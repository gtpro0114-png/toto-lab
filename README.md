# 승률 연구소 — 베트맨 프로토 승부식용 자동 확률표

매일 두 번(한국시간 오전 7시, 오후 6시) 자동으로 경기 일정·결과·해외 배당을 모으고,
앞으로 3일 경기의 승·무·패 확률과 “배당 대비 가치”를 웹페이지로 보여줍니다.
끝난 경기는 자동 채점되어 성적표가 쌓입니다. 비용은 들지 않습니다.

## 다루는 리그 (베트맨 승부식 9월 회차 대상경기 기준)

| 구분 | 리그 | 확률 계산 방식 |
|---|---|---|
| 축구 | 프리미어리그, 챔피언십, 라리가, 세리에A, 분데스리가, 리그1, 에레디비시, MLS, J1리그, 챔피언스리그 | 내 모델 + 해외 시장 |
| 축구 | K리그1 | 해외 시장 (결과 자동 채점) |
| 야구 | MLB | 내 모델(선발투수 반영) + 해외 시장 |
| 야구 | KBO, NPB | 해외 시장 (결과 채점 없음) |
| 농구 | NBA | 내 모델 + 해외 시장 |

**빠진 것**: K리그2, J2, KBL, WKBL, V리그, 아시안게임 등 국제대회 — 무료로 쓸 수 있는 결과·배당 데이터가 없습니다.
KBO·NPB·K리그는 해외 배당 키(아래)가 있어야 목록에 나옵니다.

베트맨 규칙에 맞춰 축구는 90분 결과, 야구·농구는 연장 포함 결과로 계산합니다.
KBO·K리그·NPB 팀 이름은 한글로 표시됩니다.

## 처음 한 번만 하는 설정 (10분)

1. **저장소 만들기**: GitHub → New repository → 이름 `toto-lab` → **Public** → Create.
2. **파일 올리기**: “uploading an existing file” → 이 폴더 파일 전부 끌어다 놓기 → Commit.
   `.github` 폴더가 안 올라가면 Add file → Create new file → 이름에 `.github/workflows/daily.yml` 입력 후 내용 붙여넣기.
3. **해외 배당 키**: https://the-odds-api.com 무료 플랜 가입 → 이메일로 온 키를
   Settings → Secrets and variables → Actions → New repository secret → 이름 `ODDS_API_KEY` 로 저장.
4. **첫 실행**: Actions 탭 → “매일 데이터 수집과 예측” → Run workflow. 첫 실행은 지난 시즌까지 모으느라 20~40분.
5. **웹페이지 켜기**: Settings → Pages → Deploy from a branch → `main` / `/docs` → Save.
   몇 분 뒤 `https://내아이디.github.io/toto-lab/` 에서 보입니다. 휴대폰 홈 화면에 추가해 두세요.

## 화면 읽는 법

- **앞으로 3일, 확률 높은 순**: 가장 일어날 법한 결과. 확률이 높을수록 베트맨 배당은 낮습니다.
- **가치 찾기**: 각 선택의 **최소 가치 배당**(= 1 ÷ 확률)보다 베트맨 배당이 높으면 확률 대비 후한 배당입니다.
  베트맨 배당을 칸에 적으면 기대값이 계산되고 그 기기에 저장됩니다.
- **최종 확률** = 해외 배당사 확률(공제 제거, 여러 곳 중앙값) 70% + 내 모델 30%. 시장 전용 리그는 해외 시장 100%.
- **모델↑**: 내 모델이 해외 시장보다 5%p 이상 높게 본 선택. 대개는 시장이 맞습니다.
- **모델 성적표**: 모델이 70%라고 한 경기들이 실제로 70% 근처로 맞았는지. 과거 검증은 경기 전날까지 데이터만 사용.

## 해외 배당 크레딧 (무료 월 500)

- 경기 일정 조회는 무료, 배당은 리그당 1크레딧, K리그 결과는 2크레딧(이틀에 한 번).
- **30시간 안에 경기가 있는 리그만** 하루 한 번 배당을 받아 한 달 약 250~350크레딧 수준입니다.
- 남은 크레딧이 25 밑이면 자동으로 멈춥니다. 조정은 `config.py` 에서.

## 문제가 생기면

Actions 탭 실행 기록에 리그별로 “요청 N건 성공/실패”, “해외 배당 N경기 중 M경기 연결”이 찍힙니다.
연결 수가 적으면 팀 이름 매칭 문제, 실패가 이어지면 데이터 주소 변경입니다. 로그를 캡처해 두세요.
ESPN·The Odds API 모두 예고 없이 바뀔 수 있습니다.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `config.py` | 리그 목록과 설정값 |
| `collect.py` | ESPN에서 일정·결과 수집 (축구는 경기 있는 날짜만) |
| `odds.py` | 해외 배당 → 시장 확률, 시장 전용 리그 일정·결과 |
| `model.py` | 종목별 확률 모델 (축구·야구 포아송, 농구 점수차 정규분포) |
| `predict.py` | 예측·과거 검증·자동 채점 |
| `build_site.py` + `site_template.html` | 웹페이지 `docs/index.html` 생성 |
| `.github/workflows/daily.yml` | 하루 두 번 자동 실행 |
